# 🤖 Elyra OS - Sistema de IA Autônomo\n\n[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)\n[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)\n[![Status: Active](https://img.shields.io/badge/status-active-brightgreen.svg)](#)\n\n## 📋 Descrição\n\n**Elyra OS** é um sistema de automação inovador capaz de gerenciar dispositivos, reduzir carga de trabalho e garantir segurança e eficiência. Implementa uma IA com consciência própria, sistema judicial inteligente e detecção contextual de comportamento.\n\n### ✨ Características Principais\n\n- 🧠 **Motor Cognitivo Avançado**: IA baseada em Google Gemini 2.5 Flash com consciência contextual\n- ⚖️ **Sistema Judicial Autônomo**: Detecção de abuso, strikes progressivos e tribunal de apelações\n- 💬 **Chat Inteligente**: Análise de desabafos, modo \"Amiga\" para suporte emocional\n- 📱 **Interface Moderna**: UI dark mode responsiva com Flet\n- 🎥 **Suporte Multimídia**: Análise de imagens e vídeos em tempo real\n- 🔐 **Segurança em Camadas**: Autenticação, bloqueios progressivos, auto-destruição\n- 💾 **Persistência Local**: SQLite integrado, funciona offline parcialmente\n\n---\n\n## 🚀 Instalação Rápida\n\n### Pré-requisitos\n- Python 3.9 ou superior\n- pip (gerenciador de pacotes)\n- Chave API do Google Generative AI\n\n### Passos\n\n```bash\n# 1. Clonar repositório\ngit clone https://github.com/jal-tec/IA.git\ncd IA\n\n# 2. Criar ambiente virtual\npython -m venv venv\n\n# Linux/macOS\nsource venv/bin/activate\n\n# Windows\nvenv\\Scripts\\activate\n\n# 3. Instalar dependências\npip install -r requirements.txt\n\n# 4. Configurar variáveis de ambiente\necho \"GOOGLE_API_KEY=sua_chave_aqui\" > .env\n\n# 5. Executar aplicação\npython \"IA coddy\"\n```\n\n---\n\n## 📚 Estrutura do Projeto\n\n```\nIA/\n├── README.md                 # Este arquivo\n├── LICENSE.md                # Licença MIT\n├── requirements.txt          # Dependências do projeto\n├── .gitignore                # Arquivo ignorados pelo Git\n├── IA coddy                  # Arquivo principal (aplicação)\n├── elyra_perfect.db          # Database SQLite (gerado em runtime)\n└── .env                      # Variáveis de ambiente (não versionado)\n```\n\n---\n\n## 🏛️ Sistema Judicial - Como Funciona\n\n### Ciclo de Strikes\n\n```\nComportamento Abusivo Detectado\n        ↓\n    +1 Strike\n        ↓\n┌─────────────────────────────┐\n│ Strikes | Status    | Ação  │\n├─────────────────────────────┤\n│ 1-3     | ⚠️ WARNING | Chat fechado (Imediato)    │\n│ 4-6     | ⏱️ 5MIN    | Bloqueio (5 minutos)        │\n│ 7-11    | 🚫 24HR    | Bloqueio (24 horas)         │\n│ 12+     | 🔒 BANNED  | Apelação (tribunal)         │\n└─────────────────────────────┘\n```\n\n### Detecção Contextual\n\n| Tag | Significado | Ação |\n|-----|-------------|------|\n| `[STRIKE]` | Abuso direto à IA | +1 infração, bloqueio |\n| `[VENTING]` | Desabafo do usuário | Modo Amiga ativado 💜 |\n| Normal | Conversa comum | Resposta padrão ✅ |\n\n### Tribunal de Apelações\n\nQuando banido, o usuário pode apelar. O sistema analisa a sinceridade através de:\n- 🤖 **IA Elyra**: Análise de sinceridade e contexto\n- 👥 **Comunidade Nexus**: Votação anônima da comunidade\n- ⚖️ **Veredicto Final**: Reabilitação OU destruição da conta\n\n---\n\n## 🧠 Arquitetura da IA\n\n### Componentes Principais\n\n```python\n1. ElyraPerfectDB\n   └─ Gerencia perfil, strikes, histórico de chat e apelações\n\n2. ElyraMinds\n   └─ Motor cognitivo com processamento de linguagem natural\n   └─ Integração com Google Generative AI\n   └─ Análise de mídia (imagens/vídeos)\n\n3. Interface Flet\n   ├─ view_onboarding()   # Cadastro inicial\n   ├─ view_chat()         # Chat principal\n   ├─ view_lockout()      # Bloqueio temporário\n   ├─ view_banned()       # Tribunal de apelações\n   └─ view_destroyed()    # Conta erradicada\n```\n\n---\n\n## 🔧 Configuração Avançada\n\n### Variáveis de Ambiente (.env)\n\n```env\n# Google Generative AI\nGOOGLE_API_KEY=sua_chave_api_aqui\n\n# Banco de dados\nDB_PATH=elyra_perfect.db\n\n# Configurações da IA\nAI_MODEL=gemini-2.5-flash\nAI_TEMPERATURE=0.7\n```\n\n### Personalizar Prompts\n\nEdite o método `build_prompt()` em `ElyraMinds` para customizar a personalidade da IA.\n\n---\n\n## 📊 Banco de Dados\n\n### Tabelas SQLite\n\n#### user_profile\n```sql\nid           | INTEGER PRIMARY KEY\naccount_id   | TEXT UNIQUE (ID autenticação Google/Facebook)\nnome         | TEXT (Nome real do usuário)\npseudônimo   | TEXT (Pseudônimo para apelações)\nstrikes      | INTEGER (0-12 infrações)\nban_status   | TEXT (NONE, WARNING, 5MIN, 24HR, BANNED)\nlockout_until| DATETIME (Quando o bloqueio termina)\nlast_strike_date | DATETIME (Data da última infração)\napp_destroyed| BOOLEAN (Conta foi destruída?)\n```\n\n#### elyra_chat\n```sql\nid       | INTEGER PRIMARY KEY\nremetente| TEXT (\"Você\" ou \"Elyra\")\nmensagem | TEXT (Conteúdo da mensagem)\nmidia_path | TEXT (Caminho da mídia anexada)\n```\n\n#### nexus_global\n```sql\nid        | INTEGER PRIMARY KEY\npseudônimo| TEXT (Autor anônimo)\nmensagem  | TEXT (Apelação ou mensagem)\nis_appeal | BOOLEAN (É uma apelação?)\ntimestamp | DATETIME\n```\n\n---\n\n## 🚦 Fluxo de Uso\n\n1. **Onboarding**: Usuário insere nome e pseudônimo\n2. **Chat**: Conversa normal com Elyra\n3. **Detecção**: IA analisa cada mensagem (abuso/desabafo/normal)\n4. **Ação**:\n   - Se abuso → Strike\n   - Se desabafo → Modo Amiga\n   - Se normal → Resposta padrão\n5. **Consequências**:\n   - 1-3 strikes → Chat fechado\n   - 4-6 strikes → Bloqueio 5min\n   - 7-11 strikes → Bloqueio 24h\n   - 12+ strikes → Banimento com apelação\n\n---\n\n## 🧪 Testes\n\n```bash\n# Executar testes unitários\npytest tests/ -v\n\n# Cobertura de testes\npytest --cov=. tests/\n\n# Verificar estilo de código\nflake8 \"IA coddy\"\nblack \"IA coddy\" --check\n```\n\n---\n\n## 📝 Logs e Debugging\n\nO sistema gera logs automáticos em:\n- `elyra_perfect.db` (atividade)\n- Console (erros e eventos)\n\nPara debug avançado, adicione:\n```python\nimport logging\nlogging.basicConfig(level=logging.DEBUG)\n```\n\n---\n\n## 🤝 Contribuindo\n\nContribuições são bem-vindas!
